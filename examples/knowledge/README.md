# Knowledge base

This Git repository is Brainy's single source of truth. Every document is Markdown and lives in
one of five areas, which are also the access-control spaces:

| Folder | Content |
|---|---|
| `projects/` | Projects, brands, customers — goals, decisions, status |
| `tools/` | Tools and services you run — how they work, how to operate them |
| `systems/` | Shared systems and architecture |
| `shared/` | Conventions, backlog and anything everybody needs |
| `team/` | Area shared with external collaborators |

Brainy commits every change, so the Git history is the change log.
